03 / SYSTEM WORKFLOW

자동 적재와 창고 비움은
서로 다른 운전 흐름입니다.

TEAM · 기본 자동 공정

소재를 판별하고 창고에 적재

  1. 원점 복귀자동 공정의 시작
  2. 소재 투입·가공·이송다음 공정으로 소재 이동
  3. 재질 판별금속 / 비금속 구분
  4. 창고 적재금속 → 좌측 창고
    비금속 → 우측 창고

발표자료의 만재 분기: 금속은 컨베이어 끝 박스로, 비금속은 이송 중 배출합니다. 세부 상태 전이는 추가하지 않았습니다.

담당 기능 · 별도 운전

HMI 요청으로 적재물을 배출

  1. HMI 창고 비움 요청Equipment Control의 운전 요청
  2. 실행 조건 확인자동 시퀀스 중 비움 실행 제한
  3. 실행 허용 시 적재물 배출컨베이어 끝 박스로 이송

자동 적재 다음에 항상 이어지는 단계가 아닙니다. 실행 허용의 세부 접점·PLC 내부 상태 전이는 최종 원본에서 확인하지 못했습니다.

두 공정을 하나의 연속 완료 시퀀스로 묶지 않습니다.

위 도식은 발표자료에 명시된 공정과 운전 제한을 설명합니다. 새 인터록, 오류 복구, 완료 판정 조건을 임의로 추가하지 않았습니다.

04 / IMPLEMENTATION EVIDENCE

담당 기능과
실제로 확인한 구현을 연결합니다.

01

창고 비움 · 요청과 운전 상태

Equipment Control에는 창고 비우기 버튼, 비우는 중 표시, 1~3층 적재 상태가 제시되어 있습니다. 담당 기능은 적재된 소재를 꺼내 끝 박스로 옮기는 동작입니다.

버튼의 PLC 디바이스 주소, 창고 위치별 순서, 완료 판정과 직접 작성·수정한 접점·출력 범위는 최종 원본 대조가 필요합니다.

02

작업 시간 측정 · 발표자료 스텝 282

발표자료 10쪽의 래더 캡처에서 작업 시작 M1, T5, TTMR D5000 K1을 확인했습니다. 입력 조건과 M1 유지 분기를 바탕으로 작업 시작과 시간 측정 명령이 연결된 화면입니다.

각 접점의 전체 사용처·초기화·종료 조건, 평균·누적 시간 계산식, 측정 리셋 시점과 HMI 표시 주소는 확인되지 않았습니다. 이 발췌로 전체 네트워크의 단독 작성이나 측정 정확도를 주장하지 않습니다.

03

HMI · 운전 입력과 상태 표시

Main, Equipment Control, 작업 시간 상세 화면의 구성·표시 기능에 기여했습니다. 화면별 신규 작성과 기존 화면 수정 범위는 확인 필요입니다.

위 항목은 팀 HMI 화면의 기능 설명입니다. 모든 버튼·표시를 개인 단독 구현으로 보지 않으며 화면의 예시 숫자는 실측 성능이 아닙니다.

발표자료 캡처 확인 · 최종 PLC·HMI 원본 미대조

PLC 프로그램과 HMI 프로젝트는 서로 다른 원본입니다. 화면의 기능을 확인한 것과 최종 디바이스 연결·다운로드본을 확인한 것은 구분합니다.

  • 프로그램·화면별 직접 작성·수정, 배선·장비 설정·시험 범위
  • 동일 조건의 전후 작업 시간·간섭 빈도·반복 성공률·측정 정확도
  • 실물 시연의 연속 공정 성공·반복 시험·개인 수행

HMI 표시값을 성능 수치로 바꾸지 않습니다.

발표자료의 반복 숫자는 화면 구성 예시입니다. 기존 시연의 일부 정지 프레임과 표시값도 기준 측정기에 대조한 검증값이 아니므로 대표 Tact Time·개선율로 제시하지 않습니다.

공개 코드 저장소 주소는 확인되지 않았습니다. 코드 링크·저장소 QR을 임의로 제공하지 않으며, 원본 파일·미승인 사진·영상도 이 페이지에서 공개하지 않습니다.
