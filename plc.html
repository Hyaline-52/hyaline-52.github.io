04

문제 해결 과정

PROBLEM SOLVING

01. 코드 통합 후 시퀀스 간섭

01
문제 발생
파트별 코드를 통합한 뒤 의도하지 않은 동작들이 동시에 실행됐습니다.
02
해결 과정
센서 입력이나 서보 완료 신호만으로 실행되던 루틴에 다른 동작의 실행 상태를 B접점 조건으로 추가해, 중복 실행을 막았습니다.
03
결과
루틴 간 상호 배타적인 실행 조건을 구성했습니다.
배운 점

공유 신호뿐 아니라 현재 실행 상태도 함께 확인해야 합니다.

PROBLEM SOLVING

02. 창고 비움 중 스토퍼 간섭

01
문제 발생
창고 비움 동작 중 스토퍼와 반복적으로 간섭해 기구부가 꺾이는 문제가 발생했습니다.
02
해결 과정
원인은 비움 과정의 소재 위치 보정 누락이었습니다. 흡착 전에 스토퍼 실린더로 소재 위치를 보정하도록 순서를 수정했습니다.
03
결과
스토퍼 동작 → 흡착 → 서보 이동 순서를 적용했습니다.
배운 점

소재를 이동하기 전에 위치를 먼저 맞춰야 합니다.
