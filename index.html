01 / AI & EMBEDDED4인 팀 · 개발 완료

POCO

AI 자세 코칭 모니터암

🏅 임베디드 소프트웨어 경진대회 결선 진출

프로젝트 개요

카메라로 자세를 분석하고 교정 피드백·일일 리포트를 제공하며, 정상 자세에서는 모니터 위치와 수평을 조절하는 AI 자세 코칭 시스템입니다.

개발 배경과 목표

자세 안내만으로 바뀌지 않는 작업 환경을 함께 개선하고자 했습니다. 잘못된 자세는 교정을 유도하고, 정상 자세를 기준으로 모니터가 움직이도록 자세 판단과 장치 제어를 연결했습니다.

담당 역할

Arduino 펌웨어·Serial·알림·카메라 보정 / Motor1·2 제어 연결·조건 처리·하드웨어 통합

  • Arduino
  • Python
  • Serial
  • MPU6050
  • Raspberry Pi
  • PyQt 설정 연동

02 / EMBEDDED CONTROL4인 팀 · 개발 완료

KICK-CAN

STM32 분산 임베디드 RC카

프로젝트 개요

카드 인증을 거친 사용자가 무선 조종기로 RC카를 운전하고, 차량 내부의 구동·센서·화면 장치가 CAN 통신으로 정보를 주고받는 시스템입니다.

개발 배경과 목표

실제 차량 전장의 역할 분담과 통신 구조를 작은 RC카에 구현하고자 했습니다. 조종·구동·환경 감지·상태 표시를 별도 장치로 나누고, 명령과 상태 정보를 연결하는 것을 목표로 했습니다.

담당 역할

Node 1 초음파·온도·조도 판단, FreeRTOS Task·Queue 구성, CAN 송수신

  • C
  • STM32F103
  • STM32 HAL
  • FreeRTOS
  • CAN
  • ADC / DMA

트러블슈팅

감지뿐 아니라 경고 해제까지 전달하기

문제
팀 통합 과정에서 장애물 감지 후 경고 상태가 남는 현상이 발생했습니다.
원인·검토
센서 측정 완료 여부와 CLEAR 메시지의 의미를 확인하고, 송신과 출력 노드의 책임을 구분했습니다.
해결 방식
Echo 완료 확인·대기를 추가하고 미수신·범위 밖 입력을 기존 CLEAR 처리에 연결했습니다. 송신 시 주행 방향도 다시 확인했습니다.
확인 결과
Node 1의 CLEAR 메시지 구성과 송신 경로를 수정했습니다. 확인 범위는 HAL 송신 요청 등록까지이며, Node 2 출력 완료는 포함하지 않습니다.
